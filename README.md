# AEO Analyzer 🚀

**AEO Analyzer** is a professional-grade platform designed to help brands, businesses, and developers navigate the new era of **Answer Engine Optimization (AEO)**. As search evolves from links to direct answers (via AI Overviews, Perplexity, and Gemini), this tool provides the insights needed to stay visible.

## 🌟 Key Features

- **AEO Knowledge Base:** A deep-dive FAQ and guide on how AI answer engines work.
- **Targeted Personas:** Specialized strategies for Brands, Local Businesses, and Developers.
- **Modern UI:** A high-end, editorial-style interface built with React and Tailwind CSS.
- **Interactive FAQ:** Smooth, animated knowledge base for easy navigation.

## 🛠 Tech Stack

- **Frontend:** React 18+ with TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Motion (Framer Motion)
- **Icons:** Lucide React
- **Build Tool:** Vite

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/aeo-app.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
