## Rows marked DIFFERENT (summary)

1. **Claim 1, authority.** No authority sub-score exists. Sub-scores are entity, density, clarity and structure. Authority/trust appears only as the E-E-A-T diagnostic, which has no weight in the score.
2. **Claim 2, 90 seconds.** No measured timing exists anywhere (no duration column, no timing keys, nothing logged). The figure appears only in site copy, and /blog/how-it-works applies it to sweep work that /blog/why-ai-doesnt-mention-you says takes "a few minutes".

4. **Claim 4b, fidelity.** It checks a fixed set of facts against the customer's live site: brand name, declared founders, published prices, free allowance and namesake confusion. The retired-name ("outdated name") check runs only for aeoanalyzers.com, never for customers.
5. **Claim 5b, conditional.** TRUE for all sweep reports. It is DIFFERENT only if "every report" includes the AEO Score Word report, which does not name its model.
