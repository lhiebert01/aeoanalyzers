# AEO Analyzers — Distribution Master Pack (v1, 14 Oct 2026)

Purpose: one place that lists every post in the AEO Analyzers blog series, which channels each has been pushed to, and what came back, so the whole series is tracked rather than one post at a time. Each post also gets its own standalone pack (the first is `AEO-DISTI-PACK-the-measurement-layer.md`); the standalone pack holds the copy, this master holds the record.

Maintained by Lindsay. The agent fills the URL and OG columns in section 2 on first publish of this pack (it can read the blog index); everything else is filled by hand after posting.

---

## 1. Standing rules for every channel (from the house rules, restated once)

1. No prices in any post, image, comment or email. Prices live only on the pricing page.
2. Only figures that appear on /evidence. Every figure travels with its scope (answers, engines, date).
3. No named competitors, no negative language about other tools, practices or practitioners. Our own numbers are disclosed as openness, not shortfall.
4. Measure and manage are claimed; improve is never claimed.
5. Links are bare https URLs, nothing around them. No UTM, no redirect wrappers.
6. Reddit: one comment on a live thread with the disclosure line; never a cold post; never a second link in replies.
7. Outreach emails are never follow-ups; each is a fresh email with one new dated fact. A new post is a dated fact.
8. The Search Console fan-out feature is not mentioned on any channel until "The query you never typed" is released.
9. LinkedIn first, X an hour or more later, never both within the hour. One LinkedIn post per weekday at most.
10. Every post gets a house-style OG at exactly 1200 × 630: near-black, bright green accent, kicker top-left, footer bar "AEO ANALYZERS / AEOANALYZERS.COM".
